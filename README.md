
# ☕ CaffEase

### An Automated Point of Sale System with Analytics and Performance Monitoring for 2N1 Coffee Shop

CaffEase is a web-based Point of Sale (POS) system developed for 2N1 Coffee Shop. It aims to streamline daily sales transactions, manage products and orders, and provide analytics and performance monitoring to support business operations and decision-making.

## 📌 Project Overview

This system was developed as an academic project to help improve the efficiency of coffee shop operations through a centralized digital platform.

## ✨ Key Features

- Point of Sale (POS) interface
- Product and menu management
- Order and transaction management
- Sales analytics and reporting
- Business performance monitoring

## 🛠️ Technologies Used

- **Framework:** Laravel (PHP)
- **Front-End:** HTML, CSS, JavaScript, Blade
- **Database:** MySQL
- **Development Tools:** Visual Studio Code, Git, GitHub

## 🚀 Installation

### Prerequisites
- PHP
- Composer
- MySQL
- Node.js and npm

### Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/eianjeffcatapang16-dot/CaffEase.git
   ```

2. Navigate to the project folder:

   ```bash
   cd CaffEase
   ```

3. Install dependencies:

   ```bash
   composer install
   npm install
   ```

4. Create the environment file:

   ```bash
   cp .env.example .env
   ```

5. Generate the application key:

   ```bash
   php artisan key:generate
   ```

6. Configure the database connection in `.env`.

7. Run the database migrations:

   ```bash
   php artisan migrate
   ```

8. Start the frontend development server:

   ```bash
   npm run dev
   ```

9. In another terminal, start Laravel:

   ```bash
   php artisan serve
   ```

10. Open `http://127.0.0.1:8000` in your browser.

**Note:** Additional database seed data or configuration may be required depending on the application's setup.
